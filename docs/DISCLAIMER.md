# 免责声明与服务条款

本文件是「永久删除（不进回收站）」右键菜单工具（下称"本工具"）的免责声明与服务条款。
它同时是安装器里那个「免责声明 / 服务协议」窗口的正本：窗口显示的内容就是这个文件
（编译时以资源形式内嵌进 `PermanentDeleteSetup.exe`，两者永远一致）。
首次使用前请读一遍；继续使用即视为你已经读过并同意下面全部内容。

## 1. 这个工具是做什么的

- 往 Windows 资源管理器的右键菜单里加一项「永久删除（不进回收站）」，
  也可以用同样的方式把它移除、修复、查看当前状态。
- 右键点它之后：先弹一个确认框（默认按钮是**取消**），确认后所选文件/文件夹被
  **直接删除，不经过回收站**，因此**常规手段无法恢复**。
- 它做的是"删除"，不做"找回"：本工具不提供任何数据恢复功能，也不备份被删内容。

## 2. 它用到了哪些权限和系统位置

- 右键菜单动词：只注册在 `HKLM\SOFTWARE\Classes\AllFilesystemObjects\shell\PermanentDelete`。
  写 HKLM 需要管理员权限，所以安装 / 卸载 / 修复时会弹一次 UAC。
- 引擎脚本：`%LOCALAPPDATA%\PermanentDelete.ps1` 和 `%LOCALAPPDATA%\launch_perm_delete.vbs`。
  真正执行删除的是这两个脚本，运行时用系统自带的 Windows PowerShell 5.1。
- 日志与设置：`%LOCALAPPDATA%\PermanentDelete\`（`setup.log`、`delete.log`、`setup.ini`、
  `backup-*.reg`）。全部只写在本机；卸载时的注册表备份也放在这里。
- 删除动作：调用 Windows Shell 的删除 API（`SHFileOperation`，不设回收站标志），
  由本机脚本执行，删除内容**不上传、不外发**。
- 更新检查（可关闭）：用 HTTPS 访问 GitHub 的公开接口 `api.github.com`，这是本工具
  唯一的外发请求，细节见第 4 节；设 `PERMDEL_NO_UPDATE=1` 可完全关闭。

本工具不申请常驻服务、不装驱动、不加开机启动项、不建计划任务，也不改动回收站设置；
不会读取或修改你没有选中的文件。

## 4. 数据与网络

- 本工具不收集、不上传任何个人数据、文件内容、路径或使用统计；删除日志只写在本机，
  供你自己排障。
- 界面启动时会做一次可选的"更新检查"：用 HTTPS 请求 GitHub 的公开接口
  （`api.github.com`，取不到 Release 时退到仓库的 tags 接口），只读取最新版本号。
  请求里除固定的 User-Agent（含本工具版本号）外不含任何本机信息。
- 关闭方式：设置环境变量 `PERMDEL_NO_UPDATE=1`（也接受 `true` / `yes` / `on`）。
  关闭后本工具不发起任何网络请求；命令行 `checkupdate` 属于同一类请求，只在手动执行时发出。
- 更新检查只报告"有没有新版本"，不会自动下载、不会替换文件、不会静默升级。
